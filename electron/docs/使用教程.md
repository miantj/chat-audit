# 一手聊天审计导出工具 · 使用教程

## 一、安装

### macOS

1. 根据电脑芯片下载对应安装包：
   - **Apple 芯片（M 系列）**：下载 `*-arm64.dmg`
   - **Intel 芯片**：下载普通 `.dmg`（文件名不含 arm64）
2. 打开 DMG，将「一手聊天审计导出」拖入「应用程序」文件夹。
3. 首次打开若提示「无法打开」或「来自未知开发者」，任选一种方式：
   - 在「应用程序」中 **右键 → 打开**（仅首次需要）
   - 或在终端执行：

```bash
xattr -dr com.apple.quarantine "/Applications/一手聊天审计导出.app"
open "/Applications/一手聊天审计导出.app"
```

### Windows

1. 下载并运行 `一手聊天审计导出 Setup *.exe`。
2. 按安装向导完成安装，可从桌面或开始菜单启动。

### 环境要求

| 项目 | 说明 |
|------|------|
| 浏览器 | 本机需已安装 **Google Chrome**（应用会启动专用 Chrome，不会使用 Edge 等其它浏览器） |
| 网络 | 能访问 CRM / 企微后台 |
| 账号 | 具备 CRM 导出所需权限的账号 |

---

## 二、首次使用（登录 CRM）

1. 启动「一手聊天审计导出」。
2. 应用会自动打开 **专用 Chrome 窗口**（配置目录：`~/.chrome-chat-audit-profile`）。
3. 在 **该专用窗口** 中登录 CRM，完成扫码或账号登录。
4. 登录成功后，回到导出工具主界面操作。

> **重要**
>
> - 必须在 **应用弹出的专用 Chrome** 里登录，日常使用的 Chrome 登录态 **无效**。
> - 关闭专用 Chrome 后再次打开，登录状态会保留，一般无需重复登录。
> - 若 9222 端口被其它 Chrome 占用，请先完全退出占用该端口的 Chrome 后重开应用。

## 三、导出操作

### 界面说明

| 选项 | 说明 |
|------|------|
| 导出日期 | 选择开始、结束日期；可点「昨天」「今天」快捷设置 |
| 单日导出 | 勾选后，开始与结束日期保持一致（适合只导一天） |
| 导出模式 | **有效指标客户**（默认）、**全部外部好友**、**目标名单（Excel/CSV）** |
| 目标名单 | 选择含「负责人」「外部客户ID」的 `.xlsx` / `.csv`；跨多日时自动按天导出并合并 |
| 匹配策略 | 目标名单模式下：**可见好友交集**（推荐）或 **逐个 ID 搜索** |
| 部门 | 选择要导出的部门 |
| 输出目录 | 导出文件保存位置，点击「选择」指定文件夹 |

### 操作步骤

1. 设置 **导出日期**（默认一般为昨天）。
2. 选择 **导出模式**；若选目标名单，点击 **选择** 指定 Excel/CSV 文件。
3. 选择 **部门**。
4. 点击 **选择**，指定 **输出目录**。
5. 点击 **开始导出**。
6. 观察底部状态栏与日志；导出过程中可使用 **暂停 / 继续 / 停止**。

### 导出过程中

- 状态栏会显示当前进度（员工或会话维度）。
- 日志区域会输出详细步骤，便于排查问题。
- 请勿手动关闭专用 Chrome，以免导出中断。

### 导出结果

- 文件保存在您选择的 **输出目录** 中。
- **有效指标 / 全部好友**：`chat-audit-YYYY-MM-DD.json`（全量好友为 `chat-audit-all-customers-…`）
- **目标名单（单日）**：`chat-audit-target-list-YYYY-MM-DD.json`
- **目标名单（跨多日）**：`target-list-by-day-开始_结束/` 目录下的按天文件 + `chat-audit-target-list-merged.json`
- 若提示「未产生任何会话记录」，请检查：专用 Chrome 是否已登录 CRM、日期与部门是否与后台一致。

## 四、常见问题

### 1. macOS 提示无法打开应用

见上文「安装 → macOS」中的解除隔离命令，或右键「打开」。

### 2. 专用 Chrome 未弹出或提示端口占用

- 确认本机已安装 Google Chrome。
- 退出所有 Chrome 窗口后重试。
- 仍失败时重启电脑后再启动应用。

### 3. 提示需要在专用 Chrome 中登录

- 在应用打开的专用窗口中重新登录 CRM。
- 不要使用日常 Chrome 的标签页登录。

### 4. Windows 安装后双击无反应

可查看日志（需技术支持协助）：

```bat
type "%APPDATA%\chat-audit-export\logs\bootstrap.log"
```

更多 Windows / Win7 兼容说明见项目文档 `electron/docs/win7-build-compatibility.md`。

### 5. 下载安装包时页面 404

- 请先 **登录 GitLab** 后再点击 Release 中的下载链接。
- 若仍无法下载，请联系管理员检查 Release 资源权限。
